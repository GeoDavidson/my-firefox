# my-firefox

A fully customized minimal Firefox setup. Clone and run one script to restore everything on any new computer.

---

## What it includes

- Compact horizontal tab bar — minimal styling, transparent unselected tabs
- Styled window controls (minimize/maximize/close) — subtle at rest, hover effects, red close on hover
- No back/forward buttons, no reload button
- No site identity / "Verified by" icon in the URL bar
- Minimal bookmarks toolbar centered under the URL bar
- Custom new tab page — clean blank page showing your bookmarks with favicons, no Firefox search bar
- All about:config settings applied automatically via `user.js`

---

## Fresh Computer Setup

> Do this every time you reset or get a new computer.

1. Install Firefox and **open it once** so a profile is created
2. Clone this repo:
   ```
   git clone https://github.com/GeoDavidson/my-firefox
   ```
3. Right-click `setup.ps1` → **Run with PowerShell**
4. Restart Firefox

No admin rights required. Everything is applied automatically.

```

    ├── manifest.json            — extension metadata
    ├── newtab.html              — custom new tab page (edit this to change bookmarks)
    ├── newtab.xpi               — unsigned package (generated by build.ps1, not committed)
    └── newtab-signed.xpi        — Mozilla-signed package (committed, installed by setup.ps1)
```

## Updating the New Tab Page (bookmarks)

> Do this whenever you want to add, remove, or change bookmarks on the new tab page.

1. Edit `extension/newtab.html` — each bookmark is an `<a>` tag in the grid
2. Run `build.ps1` to repackage:
   ```
   Right-click build.ps1 → Run with PowerShell
   ```
3. Go to your AMO developer page:
   https://addons.mozilla.org/developers/addon/my-new-tab/versions
4. Click **Upload New Version** → upload `extension/newtab.xpi`
5. Download the newly signed `.xpi` Mozilla sends back
6. Save it as `extension/newtab-signed.xpi` (replace the old one)
7. Commit and push:
   ```
   git add .
   git commit -m "Update bookmarks"
   git push
   ```

## Updating userChrome.css

> Do this to change Firefox UI styling.

1. Edit `chrome/userChrome.css`
2. Copy it to your Firefox profile to test:
   ```
   %APPDATA%\Mozilla\Firefox\Profiles\<your-profile>\chrome\userChrome.css
   ```
3. Restart Firefox to apply
4. When happy, commit and push:
   ```
   git add .
   git commit -m "Update userChrome"
   git push
   ```

## about:config Settings (user.js)

These are applied automatically by `setup.ps1`. For reference:

| Preference | Value | Why |
|---|---|---|
| `toolkit.legacyUserProfileCustomizations.stylesheets` | `true` | Enables userChrome.css |
| `extensions.autoDisableScopes` | `0` | Allows sideloaded extensions |
| `extensions.startupScanScopes` | `15` | Scans profile extensions folder on startup |

## Extension Signing (first time only)

The new tab extension must be signed by Mozilla. This was already done — `newtab-signed.xpi` in this repo is the signed version. You only need to re-sign when you update `newtab.html` (see workflow above).

**If starting from scratch (lost the signed .xpi):**

1. Go to https://addons.mozilla.org/developers/
2. Sign in → **Submit a New Add-on** → choose **On your own** (unlisted)
3. Upload `extension/newtab.xpi` (build it first with `build.ps1`)
4. Answer **No** to the source code question
5. Download the signed `.xpi` → save as `extension/newtab-signed.xpi`
6. Commit to repo

Extension ID: `newtab@georg-davidson-firefox`
AMO page: https://addons.mozilla.org/developers/addon/my-new-tab/

## Firefox Version

Built and tested on **Firefox 149** (Windows 11). Some CSS selectors (especially `#trust-icon-container`) may need updating on future Firefox versions — use the Browser Toolbox (`Tools → Browser Tools → Browser Toolbox`) to inspect and find updated selectors.
